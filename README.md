# 우리는, 시빅해커

AI로 사회문제를 발견하고 해결책까지 만들어보는 **시빅해킹 해커톤 강의자료**입니다.

**강의자료 보기 → https://weniv.github.io/civichacks/**

## 무엇을 하는 수업인가요

반나절 안에 내 주변의 불편 하나를 골라 `요구사항.md` 한 장에 적고, AI와 함께 웹페이지로 만들어
친구에게 보낼 수 있는 진짜 링크까지 만들어 봅니다. 경쟁하지 않습니다. 평가하지 않습니다.

학생이 만드는 것은 두 개, 제출하는 것은 하나입니다.

| 구분 | 내용 |
| --- | --- |
| 만들 것 | `index.html` (대문페이지) + `pre.html` (발표자료) |
| 제출할 것 | GitHub Pages 링크 하나 |
| 발표 | 팀당 3~5분 |

## 진행 흐름

1. **문제 발견** — 해결책 말고 불편했던 '장면'을 적습니다
2. **주제 좁히기** — 반나절 안에 웹페이지 한 장으로 되는 크기까지 자릅니다
3. **요구사항.md** — 목적과 기능을 내 말로 씁니다 (오늘의 핵심)
4. **다듬기** — AI에게 읽히고 빠진 곳과 애매한 문장을 고칩니다
5. **만들기** — 「요구사항.md를 읽고 대문페이지 index.html과 발표자료 pre.html을 작성해줘」
6. **배포 · 발표** — GitHub Pages로 올리고, 링크를 제출하고, 3~5분간 이야기합니다

## 강의자료에 들어있는 것

- 눌러보는 6단계 로드맵 (단계별로 알아야 할 것 · AI에게 물어볼 말 · 남길 것)
- 주제 찾기 도구 — 9개 분야 × 5개 범위, 27개 주제 예시
- 주제 점검 도구 (오늘 안에 되나 / 도움이 되나 / 내가 궁금한가)
- 복사해서 쓰는 `요구사항.md` 템플릿과 프롬프트 6종
- 체크리스트 10개 (브라우저에 진행 상태 저장)
- 인터넷에 올리는 4단계(위니북스 배포 교안 링크 포함), 공공데이터 자료실

## 구조

```
index.html                  강의자료 본문 (빌드 없는 단일 파일)
요구사항.md                  이 페이지를 만들 때 실제로 사용한 요구사항 문서
archive/2020-original/      2020년 원본 강의자료 (pptx)
```

`index.html`은 외부 의존성이 없는 단일 파일입니다. 저장소를 내려받아 브라우저로 열면 바로 동작합니다.

## 원본에 대하여

AI 시대의 반나절 해커톤 과정으로 다시 구성했습니다. 원본 자료는 `archive/2020-original/`에 그대로 두었습니다.
